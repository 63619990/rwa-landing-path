# RWA 落地流程与路径设计器（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
当你需要为一项实体资产设计端到端 RWA 落地路线图，或要厘清"境内做到哪一步必须停、境外从哪一步衔接"时使用本技能。覆盖 RWA 十环节作业手册（A 资产识别→J 市值管理）+ 境内（A-G）境外（H-J）双层合规路径 + 六构件可代币化评估 + 四阶递进节奏。当用户说"想做充电桩/光伏/农产品上链融资""境内资产怎么合规出海""RWA 第一步怎么走""境内止步点在哪里"时激活。不适用于：单纯判断某说法是否触碰金融红线（用 S2）、只判断项目属于哪类主导模式（用 S3）、只规划香港沙盒/SPV 通道（用 S10）。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `rwa-landing-path`，或用 CLI：
```bash
clawhub skill install rwa-landing-path
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/rwa-landing-path.git
cp -r rwa-landing-path/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `rwa-landing-path/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
